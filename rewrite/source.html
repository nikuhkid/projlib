Extract the adaptations archive and run npm ci --ignore-scripts, then npm run build:rewrite with Node.js 22 or later and tar available. The resulting browser assets are in .local/rewrite-assets/. The included README describes the source layout and upstream build.

The archive includes the readable WebAssembly bridge and its Cargo lockfile under rewrite/adblock-engine/, and Brave's original cosmetic source under rewrite/adblock/vendor/. Build the bridge with Rust and the wasm32-unknown-unknown target, or use the repository's isolated engine build workflow. The recorded compiler and vendored dependency sources accompany the binary. Normal frontend builds use the checked-in, verified engine and filter snapshot.
